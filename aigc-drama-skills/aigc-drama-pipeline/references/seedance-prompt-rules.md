## B · 八角笼 8 项自检（每段必跑，缺一项即 REWORK）

| # | 检查项 | 通过标准 | 不过怎么修 |
|---|--------|---------|-----------|
| **1** | 开头 3s 钩子 | 第一帧有人脸 + 3s 内有冲突/接触 | 把 0-3s 改写为人脸特写 + 第一句台词 |
| **2** | 节奏密度 | 全段对白+音效 ≥ 2 条；无任何连续 >3s 静默 | 在静默段补 SFX/BGM 转场或追加一句台词 |
| **3** | 情绪顶点 | 每段至少 1 个明确情绪 beat（吻/爆发/承诺/反转） | 把第 4 段（11-14s）升级为情绪顶点帧 |
| **4** | 服装具体 | 颜色 + 款式词，无"晚宴正装"等模糊词 | 替换为"石板灰高定西装三件套+白色暗纹衬衫+黑色丝质领带" |
| **5** | 服装锁定声明 | 总述里有 `【服装锁定：全段X-Xs，@图片1[...]；@图片2[...]。禁止换装、禁止漂移。】` | 在提示词最开头加这一句 |
| **6** | 时长正确 | 15s + 时间戳一致 + 段标题对（Seg1=0-15s，Seg2=15-30s，Seg3=30-45s） | 重新核对段号与时间戳 |
| **7** | 引用完整 | 每段每个时间戳首次出现该角色都要写 `@图片N` | 给所有缺失角色名前加 @图片N |
| **8** | 禁止句 | 末尾有 `禁止：任何字幕、水印、logo、品牌标志` | 在提示词最末尾追加这一行 |

## C · 15s 段最佳节奏模板

```
0-3s    钩子段        即时人脸 + 冲突/接触 + 第一句台词
3-7s    发展段        动作推进 + 台词 ×1-2
7-11s   转折段        情绪转向 / 视觉变化 + 台词 ×1
11-14s  情绪顶点段    吻 / 爆发 / 承诺帧 + 核心台词
14-15s  余韵/钩子段   截断感 / 下集引子
```

每段 ≥ 3 条台词，每个时间块都有 SFX 或 BGM 标注。

---

## D · 5 条铁律（违反任何一条即 REWORK）

### D.1 节奏密度铁律
全段对白 + 独白 + 音效 ≥ 2 条；无任何连续 >3s 静默。
**为什么**：TikTok 观众静默 3s 就划走，必须保持音频充盈。

### D.2 服装锁定
每段开头必须有 `【服装锁定：全段X-Xs，@图片1[color+style]；@图片2[color+style]。禁止换装、禁止漂移。】`。
**为什么**：不锁定 → AI 每帧服装漂移，剪不到一起。

### D.3 对白格式 —— 全部说出来，禁止 V.O./内心独白
所有"内心戏"必须改写成人物大声说出口的对白或自言自语。
**为什么**：V.O. 在 AI 模型上控不住嘴型 —— 闭着嘴说话穿帮。这是 13 集 EP06-07 用真实生成失败换来的教训。
**写法**：
- ❌ `V.O.：他终于来了。`
- ✅ `@图片1自语，气音：「...你终于来了。」`

### D.4 角色引用完整
每段每个时间戳首次出现该角色都要写 `@图片N`。
**为什么**：缺引用 → AI 用陌生人脸生成，整段废。
**写法**：
- ❌ `Kace 站在窗前。`
- ✅ `@图片1 Kace 站在窗前。`

### D.5 禁止句必含
每段末尾必须有：`禁止：任何字幕、水印、logo、品牌标志`。
**为什么**：AI 倾向于幻觉出字幕和品牌标志，不显式禁掉就一定出。

## E · 服装锁定写法对照

| ❌ 模糊（AI 漂移） | ✅ 具体（颜色+款式锁住） |
|--------------------|--------------------------|
| 晚宴正装 | 石板灰高定西装三件套 + 白色暗纹衬衫 + 黑色丝质领带 |
| 居家服 | 米白色羊绒套头毛衣 + 浅灰色家居长裤 |
| 礼服 | 象牙白丝质衬衫 + 米色羊毛长裤 + 米色乐福鞋 |
| 运动装 | 深灰色连帽卫衣 + 黑色运动长裤 + 白色运动鞋 |
| 高定正装 | 黑色定制双排扣大衣 + 黑色丝质衬衫 + 黑色羊毛长裤 |

**规则**：颜色（具体色名，不能是"暗色") + 款式（明确品类，不能是"正装"）+ 必要时材质（丝质/羊绒/羊毛）。

## F · 对白写法对照（V.O. 改造）

| 场景 | ❌ V.O. 写法 | ✅ 显式说出来 |
|------|-------------|---------------|
| 内心戏 | `V.O.（凯斯）：终于等到这一天。` | `@图片1低语，气音：「终于等到这一天。」` |
| 回忆 | `V.O.（陈泽）：那年我们在天台...` | `@图片2眼神望远，喃喃：「那年我们在天台...」` |
| 心声 | `V.O.：我喜欢他。` | `@图片1对@图片2，语气微颤：「我喜欢你。」` 或 `@图片1独自，对镜中自己：「你喜欢他。」` |
| 评论 | `V.O.：所有人都不知道...` | `@图片1对镜头打破第四面墙：「所有人都不知道。」`（限喜剧/POV） |

## G · 提交前的安全词扫描（必跑）

按 [`safety-wordlist.md`](safety-wordlist.md) 跑一遍快速扫描：

```
高潮|婚礼|神父|誓言|婚房|应援|演唱会|演出票根|灯牌|站姐|私生|自杀|自残|品牌
```

任何命中 → 按 `safety-wordlist.md` 的替换表替换 → 重跑扫描 → 全清才能提交。

## H · 常见提交失败 → 现场处理

| 错误返回 | 含义 | 现场处理 |
|---------|------|---------|
| `OutputVideoSensitiveContentDetected.PolicyViolation - copyright restrictions` | 输出视频疑似版权 | 检查是否含真实品牌/演出/应援场景，按 safety-wordlist A 表替换 |
| `OutputVideoSensitiveContentDetected.PolicyViolation`（其他） | 输出视频敏感（亲密镜头过长/过近） | **降级三步走**：1) 缩短吻戏时长到 1-1.5s；2) 去除舌部 / 呻吟 / 喘息节奏；3) 仍拒才退到「唇即将相触，气息相缠，切黑」。**真吻本身允许**，是时长 + 描写细节触发的拦截 |
| `Input text may contain sensitive information` | 提示词文本敏感 | 重跑 safety-wordlist 扫描，特别是组合词（婚礼+神父+誓言） |
| 嘴型与台词不同步 | V.O. 没改成显式 | 全文搜 `V.O.`，按 F 表改造 |
| 角色脸漂 | 缺 `@图片N` | 全文搜角色名，前面没 @图片N 的全部补上 |

每次失败都要在 `_meta/risk-register.md` 记一条，避免重复踩坑。
