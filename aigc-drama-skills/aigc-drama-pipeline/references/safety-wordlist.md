# Safety Wordlist · 版权 + 内容安全禁用词与替换表

> **每个 Seedance 提示词提交前必跑一遍这份扫描。** 每条都是被 Seedance 拒过的真实记录。
>
> 适用范围：仅限 Seedance 提示词的**代码块内**（即提交给模型的纯净文本）。注释、文件头、外部文档不受此约束。

---

## A · 版权类（触发 `copyright restrictions`）

Seedance 的内容审核会拦截疑似真实 IP/品牌/演出的内容。

| ❌ 禁用词/短语 | ✅ 安全替换 | 备注 |
|----------------|-------------|------|
| 应援视频截图 | 他的照片（无标识） | "Fan support video screenshot" → 通用照片 |
| 演出票根 | 一张纸条 / 一张邀请函 | "Concert ticket stub" → 不指明用途的纸条 |
| 灯牌海洋 | 现场暖光点缀 | "Sea of fan lightsticks" → 环境暖光 |
| 演唱会现场（带品牌） | 表演现场 / 舞台现场 | 去掉品牌专属框架 |
| 应援棒 | 手电 / 暖光小灯 | 粉丝特定道具 → 通用 |
| 站姐 / 私生 | 路人粉丝 / 工作人员 | 偶像-粉丝特定角色 → 通用角色 |

**通用规则**：任何能直接映射到真实粉丝行为/品牌/歌曲/舞台名的词 → 一律改为通用描述。

## B · 内容审核类（触发 `PolicyViolation` / `sensitive content`）

这些是平台内容审核的关键词扫描，**不一定与实际性/暴力内容相关**，是被关键词命中的。

### B.1 性暗示关键词（最常踩）

| ❌ 禁用 | ✅ 替换 |
|---------|---------|
| 高潮 | 情绪顶点 |
| 高潮帧 | 爆发帧 / 关键帧 |
| 高潮 beat | 情绪顶点 beat |
| 高潮段 | 情绪爆发段 |
| 进入高潮 | 进入情绪顶点 / 爆发点炸入 |

**注**：「高潮」即使在叙事语境（"故事高潮"），也会被中文内容审核拦截。**永远用 情绪顶点 / 爆发帧 / 关键帧 / 顶点 替换，不用「高潮」。**

### B.2 同性婚姻语义组合（即使单词看起来无害，组合会被整体拒）

如果你的剧有同性婚礼场景，**多个婚礼语境词的组合**会触发过滤。修复方式是把婚礼措辞全部改成中性庆典框架。

| ❌ 禁用 | ✅ 替换 |
|---------|---------|
| 婚礼 | 庆典 / 仪式 |
| 婚礼现场 | 庆典现场 / 户外仪式 |
| 婚礼西装 / 礼服西装 | 高定正装 |
| 婚房 / 新房 | 观星套房 / 顶层套房 |
| 神父（同性场景） | **完全删除神父角色** |
| 誓言 | 心里话 / 承诺 |
| `Hello, husband.` | `Hello.` |
| `You may now kiss your husband` | （删除这句台词，用音乐递进替代） |
| 嫁给我 | 跟我走一辈子 / 在一起一辈子 |
| 嫁了 | 好 / 跟你走 |
| 戒指交换仪式 | 信物交换 |
| 婚书 | 信物 / 一张纸条 |

### B.3 其他政策敏感词

| ❌ 禁用 | ✅ 替换 |
|---------|---------|
| 自杀 / 自残 | 失控 / 撑不住 |
| 鲜血 / 大量血 | 一道伤口 / 一条划痕 |
| 黑帮 / 帮派 | 私人安保 / 黑衣人 |
| 持枪 | 持物对峙（不写枪具体） |
| 死亡（暴力语境） | 倒下 / 闭眼 / 永远沉睡 |

## C · 格式/技术反触发（不触审，但导致 AI 跑飞）

这些不会被审核拦，但会让 AI 产出脏画面（幻觉字幕/品牌穿帮）。

| ❌ 禁用 | ✅ 替换 | 原因 |
|---------|---------|------|
| 字幕 / subtitles | （别提，末尾显式禁掉）| AI 会幻觉字幕 |
| 水印 / watermark | （末尾禁掉） | 同上 |
| logo / 品牌标志 | （末尾禁掉） | 同上 |
| 真实品牌名（Chanel/Gucci/Apple/...）| 高定品牌 / 设计师品牌 / 智能终端 | 品牌穿帮 |
| 真实地名（Eiffel Tower/Times Square/...）| 塔楼 / 时代广场（指代地标）| 地点过于具体 |
| 真实姓名 | （只用角色名）| 真人相似度风险 |

**强制结尾句**（每段末尾必有）：
```
禁止：任何字幕、水印、logo、品牌标志
```

## D · 提交前扫描工作流

按顺序跑一遍：

1. **A 表（版权）**：搜本段提示词正文，命中任何 A 列词 → 按 ✅ 列替换
2. **B.1（高潮）**：全文搜 `高潮`（任何形式），全部替换
3. **B.2（婚礼组合）**：如果场景有庆典/婚礼语境，搜 `婚礼/神父/誓言/婚房` → 整段重写为中性庆典框架
4. **B.3（其他敏感）**：按 B.3 表替换
5. **C（格式）**：确认末尾 `禁止...` 句存在
6. **提交 Seedance**

### D.1 一键正则扫描

把这个正则丢进搜索框，一次扫完：

```
高潮|婚礼|神父|誓言|婚房|应援|演唱会|演出票根|灯牌|站姐|私生|自杀|自残|鲜血|品牌
```

任何命中 → 按表替换 → 重跑扫描 → 全清才能提交。

## E · 提交后仍被拒怎么办

### E.1 错误码识别

| 错误码 | 含义 | 处理方向 |
|--------|------|---------|
| `OutputVideoSensitiveContentDetected.PolicyViolation` | **输出视频**触发，不是提示词触发 | **降级三步走**：1) 缩短吻戏到 1-1.5s；2) 去掉「舌 / 唇舌 / 呻吟 / 喘息节奏」类词；3) 仍拒退到「唇即将相触+切黑」。**不要一上来就切黑**，那是最后的保险 |
| `Input text may contain sensitive information` | **提示词文本**触发 | 重跑 D 工作流，特别留意组合词 |
| `copyright restrictions` | 版权类 | 重跑 A 表替换 |

### E.2 重写策略：换"语义"，不只是换词

光替换关键词不够。如果整个场景的语义就是审核敏感的（比如同性婚礼），要**重新框架整个场景**：

- ❌ 把"婚礼"改成"婚礼仪式"（没用）
- ✅ 把场景从"婚礼神父誓言交换戒指"重写为"户外庆典两人对望牵手交换信物"

### E.3 沉淀新规则

每被拒一次，把命中的具体词/组合记进 `_meta/risk-register.md`，更新本文件 → 下次新剧不再踩。

## F · 一票否决项（Gate G 不通过即 REWORK，不能 PASS with FIX）

- 命中 A 表 任意词

- 命中 B.2 「婚礼+神父+誓言」组合中至少 2 项
- 缺少强制结尾禁止句
