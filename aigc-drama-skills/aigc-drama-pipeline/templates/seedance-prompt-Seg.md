## 四、八角笼自检（8/8）

- [ ] 1. 开头 3s 钩子：第一帧人脸 + 3s 内冲突/接触
- [ ] 2. 节奏密度：≥2 条音频事件，无 >3s 静默
- [ ] 3. 情绪顶点：11-14s 段有明确顶点 beat
- [ ] 4. 服装具体：颜色 + 款式齐全，无模糊词
- [ ] 5. 服装锁定声明：开头有 `【服装锁定...】`
- [ ] 6. 时长正确：15s + 时间戳一致 + 段标题对（Seg{{N}} = {{TIME_RANGE}}）
- [ ] 7. 引用完整：每段每角色都有 `@图片N`
- [ ] 8. 禁止句：末尾有 `禁止：任何字幕、水印、logo、品牌标志`
