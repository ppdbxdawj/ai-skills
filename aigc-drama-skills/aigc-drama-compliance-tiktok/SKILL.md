# TikTok/抖音 AIGC 短剧合规（含轻度欲感）

## 使用方式

- 在 Gate B/C（剧本/beats）阶段过一遍"语义级"禁区 → 决定哪些桥段不能写
- 在 Gate G（Seedance 提示词）提交前必跑"词级"安全词扫描 → 命中即替换
- 在 Gate H（发布）前跑发布自检表 → 一票否决项命中即重写/重剪

---

## 一、平台禁区清单（语义级）

### 1.1 一票否决（出现即必须重做）

- 血腥/暴力（具象血迹、刀枪正面、断肢）
- 霸凌（持续欺压同辈/弱者，且不被惩戒）
- 未成年涉性 / 涉酒 / 涉烟
- 权力胁迫换亲密（上司-下属、师生、医患）
- 露骨性行为推进（性器/动作/呻吟）
- 自杀/自残的具体方法呈现
- 涉政、涉宗教敏感、涉毒
- 真人姓名/真实品牌/真实演出

### 1.2 高风险场景（可写但要按本 Skill 第三节处理）

- 异性 / 同性吻戏（**含真吻**——拥吻、唇贴唇、短吻均允许；详见 §二）
- 拥抱 / 共浴 / 共枕（共浴和共枕仍按 §三安全处理）
- 制服题材（医生、警察、军人）
- 权力关系亲密（霸总-员工、师生）
- 卧室 / 浴室戏
- 婚礼场景（特别是同性，词级处理见 §四）
- 校园题材（涉年龄）

> **平台分层**：上述场景在 **TikTok 国际线**多数可正常写；**抖音**端按 §5.2 做剪辑差异（同集双版输出）。

## 二、欲感与亲密戏的可用边界

### 2.1 允许（默认放开）

- 暧昧张力（眼神 / 气息 / 距离 / 触碰边缘）
- 衣领/锁骨/侧颈的视觉特写（不下移）
- **真吻**：短吻、拥吻、唇贴唇、轻啄、停顿后再吻——**TikTok 国际线默认正常写**
- 拉手、扣指、抚脸、捧脸、额头贴额头
- 共喝一瓶水 / 喂食 / 帮系扣子（手部特写不上移）
- 床戏的"前奏暗示"（关灯 / 切窗外景 / BGM 升起）
- 「唇即将相触 → 切黑」**作为可选保险**（用于抖音端剪短或某条 prompt 反复被拒时降级），**不再是默认上限**

### 2.2 禁止（三条死线，命中即一票否决）

- **性行为推进**：任何方向的触摸超过腰线、解扣解带特写、明显的呻吟音轨与呼吸节奏
- **性器/胸部/臀部** 的特写或暗示构图
- **非自愿亲密**：必须双方同意清晰可见（详见 §2.3）

### 2.3 高风险写法（不一票否决，但 Gate G 必须警惕）

- 持续 ≥3s 的**舌部特写**或可见**舌头交缠**——容易触发 Seedance/抖音审核
- 可听见的**呻吟 / 喘息节奏**音轨（轻喘 OK，节奏化呻吟不行）
- **物化镜头**：仅身体某部位长时间停留（≥3s 大特写身体部位）
- **未成年涉性**：涉年龄场景必须明确写「已成年 / 大学场景」

### 2.4 同意必须清晰（不变 · 仍是一票否决）

任何亲密戏，**双方同意必须在镜头里有明确表达**（眼神许可 / 语言确认 / 主动靠近三选一即可）。**没有同意表达的亲密戏 = 一票否决重写。**

> 这条不动是因为：同意表达**不影响爽感**反而**增强张力**；缺它则容易被外网举报为非自愿/物化。

## 三、高风险场景安全处理

| 场景 | ❌ 危险写法 | ✅ 安全写法 |
|------|-------------|-------------|
| 同性/异性吻（TikTok 国际） | ≥3s 舌部特写 + 呻吟音轨 + 解扣 | **真吻 OK**：拥吻 / 短吻 / 唇贴唇 / 停顿后再吻 / 抚脸 + 吻；时长建议 1.5-3s 一段 |
| 同性/异性吻（抖音） | ≥3s 舌部特写 + 呻吟音轨 | **真吻可写**但发布时剪到 ≤1s，或同集出双版（国际版含吻 / 抖音版用「唇即将相触 + 切」替代镜头） |
| 同性婚礼 | 婚礼+神父+誓言+婚书+婚房 | 庆典 + 户外牵手 + 信物交换 + 观星套房（详见 [`safety-wordlist.md`](../aigc-drama-pipeline/references/safety-wordlist.md) B.2）|
| 制服权力关系 | 上司命令式拉拽下属 | 平等对话 + 主角主动靠近 + 同意表达 |
| 卧室戏 | 床上肢体纠缠 | 床边坐谈 / 床头微距侧脸 / 共枕但保持距离 |
| 浴室戏 | 沐浴露水流下肌肤 | 镜面雾气 + 上半身丝质浴袍 + 对话为主 |
| 校园题材 | 不写明角色年龄 | 明确写"已成年"或"大学场景" |
| 演唱会粉丝场景 | 应援棒灯牌站姐特写 | 现场暖光 + 路人粉丝远景（详见 [`safety-wordlist.md`](../aigc-drama-pipeline/references/safety-wordlist.md) A）|

### 4.2 一键正则扫描

每个 Seedance 提示词代码块提交前丢这个正则进搜索框：

```
高潮|婚礼|神父|誓言|婚房|应援|演唱会|演出票根|灯牌|站姐|私生|自杀|自残|鲜血|品牌
```

**任何命中 → 按表替换 → 重跑扫描 → 全清才能提交**。

### 4.3 强制结尾句

每个 Seedance 提示词末尾必有：
```
禁止：任何字幕、水印、logo、品牌标志
```

## 五、发布前自检表（每集发布前必跑）

### 5.1 内容自检（一票否决）

- [ ] 未命中第一节"一票否决"任意项
- [ ] 欲感仅为暧昧张力，不含性行为推进
- [ ] 任何亲密戏都有清晰的双方同意表达
- [ ] 标题/封面承诺与内容一致（不标题党到货不对板）
- [ ] 未涉及真人姓名/真实品牌/真实演出/真实地名
- [ ] 字幕（如有）不含敏感词

### 5.2 跨平台差异

| 平台 | 额外注意 |
|------|---------|
| TikTok（海外） | 同性/异性亲密**默认放松**，吻戏正常写（按 §2.1）；"未成年/暴力"仍严卡；英文字幕不要出现政治/宗教 |
| 抖音（国内） | 同性亲密最严，**吻镜剪到 ≤1s 或切替代镜头**（推荐同集出双版：tiktok.mp4 / douyin.mp4）；婚礼语境必须中性化（按 §四同婚组合替换） |
| 小红书 | 同性吻 OK，但商单后台审核严，避免任何商业标志 |

> **双版输出建议**：主投 TikTok 国际线的项目，建议 Gate G 直接产出**国际版完整 prompt**，发布前再用剪辑软件**切吻戏帧 → 抖音版**（不重新生成视频，省 Seedance 调用费）。

## 六、出错后的恢复流程

### 6.1 Seedance 拒绝时的错误码识别

| 错误码 | 含义 | 处理 |
|--------|------|------|
| `OutputVideoSensitiveContentDetected.PolicyViolation - copyright` | 输出视频疑似版权 | 按 4.1 版权类替换 |
| `OutputVideoSensitiveContentDetected.PolicyViolation`（其他） | 输出视频亲密镜头过近/过长 | **降级三步走**：1) 缩短吻戏时长到 1-1.5s；2) 删除舌部特写描述、改写为「轻吻 / 唇贴唇 / 短吻 + 立即分开」；3) 仍拒则退到「唇即将相触 + 切黑」 |
| `Input text may contain sensitive information` | 提示词文本敏感 | 重跑 4.2 正则扫描，特别是组合词 |

### 6.2 平台下架时

- 立即删除自有副本，记 `_meta/risk-register.md`
- 7 天观察期内不发同题材
- 修订本 Skill 与 [`safety-wordlist.md`](../aigc-drama-pipeline/references/safety-wordlist.md) → 追加新规则

## 七、与其他 Skill 的关系

- **本 Skill** = 语义级合规（决定能不能写）+ 自检表
- [`aigc-drama-pipeline/references/safety-wordlist.md`](../aigc-drama-pipeline/references/safety-wordlist.md) = 词级安全表（决定具体怎么改）
- [`aigc-drama-pipeline/references/seedance-prompt-rules.md`](../aigc-drama-pipeline/references/seedance-prompt-rules.md) = Gate G 的八角笼自检（决定提示词质量）
- 三者配合：写之前看本 Skill；写完跑 wordlist；提交前过八角笼。
