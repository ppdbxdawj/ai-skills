# Seedream 生图提示词助手 + Ark API 生图

Seedream 5.0/4.0 是字节跳动的 AI 图像生成模型，在即梦 AI、剪映、CapCut、火山方舟上线。

在 AIGC 短剧工作流中，Seedream 用于**生成角色参考图**，配合 seedance2-video skill 进入视频制作流程。

## 核心能力

| 能力 | 说明 |
|------|------|
| **实时联网检索** | 提示词含时效词时自动联网获取最新信息 |
| **多步逻辑推理** | 理解抽象概念 → 拆解为视觉指令 |
| **多轮对话编辑** | 迭代优化：局部修改、风格迁移、元素增删、文字渲染 |
| **高分辨率** | 原生 2K，AI 增强 4K，2-5 秒生成 |
| **角色一致性** | 保持面部/服装/姿势跨图一致（分镜必备） |
| **文字渲染** | 99%+ 中英文准确率，用引号标注文字内容 |
| **多图输入** | 最多 10 张参考图，组合/迁移/替换/衍生 |
| **组图输出** | 一次最多 15 张，内容关联，适合分镜/表情包 |

## 提示词结构

### 基础结构（文生图）

```
[主体描述] + [行为/动作] + [环境/背景] + [材质/质感] + [光影效果] + [构图要求] + [风格关键词]
```

- 主体+行为+环境用**自然语言**描述
- 风格/色彩/光影/构图用**短词**点缀
- 文字内容用引号标注：`"Hello World"`

### 四段式结构（进阶）

```
主体 → 环境 → 材质/质感 → 光影
```

### 编辑提示词公式

```
变化动作 + 变化对象 + 变化特征
示例："将骑士的头盔变为金色"
```

## 常用提示词模板

### 短剧角色参考图（核心场景）

为 Seedance 2.0 视频生成准备的角色参考图，需要**正面、高清、竖构图、电影感光影**：

```
一位[性别年龄外貌]，[瞳色]，[面部特征描述]，[发型发色]，[肤色]。
穿[服装描述]。表情[情绪]，眼神[特征]。
[光线色调]。[构图]，竖构图，高清人像，电影感光影。
```

**示例（欧美男主角）**：

```
一位欧美男性（约28-30岁），深邃灰蓝瞳色，高眉骨深眼窝，下颌线棱角分明，
鹰钩鼻，厚唇紧抿，1mm深色胡茬，深棕短发侧分背头（发胶定型），
健康小麦色皮肤。穿黑色高定西装（质感细腻），深色衬衫解一粒扣，
手腕金属质感手表。表情冰冷克制，眼神锐利带压迫感。
暗蓝色调光线，侧光打轮廓。四分之三正脸，竖构图，高清人像，电影感光影。
```

**示例（韩式男配角）**：

```
一位韩式男性（约22-24岁），清冷骨相脸，小鹿眼（深棕瞳色），
冷白皮带通透感，银灰挑染短发（鲻鱼头/狼尾），身材纤细但有线条。
穿闪光舞台服（银色/深色系），耳钉可见。
表情清冷疏离但眼神有少年感。冷白舞台灯光。
侧脸或四分之三正脸，竖构图，高清人像，电影感光影。
```

## 进阶技巧

### 1. 联网触发
提示词中含时效词时自动联网：`2026年流行色` `最新款XX` `今年XX趋势`

### 2. 图像编辑
- **指定区域**："将图中[区域]替换成..."
- **风格迁移**："保持内容不变，改成[风格]"
- **元素控制**："为画面增加/移除[元素]"
- **光影调整**："将画面光影改为[光线名称]"

### 3. 文字渲染
将需要生成的文字放入引号：`图片中央写着"创意无界"`

### 4. 构图控制
- 黄金分割：`三分法构图` `黄金螺旋`
- 视角：`俯视鸟瞰` `仰视` `正面平视` `45度斜角`
- 留白：`大量留白` `简洁背景` `主体偏[方向]`

### 5. 多图融合
最多支持 14 张参考图：`参考图1的风格，图2的色调，图3的人物姿势`

### 6. 组图生成
触发词：`一系列` `组图` `生成N张连续的` `分镜图`

## 负向提示词

明确说明不需要的元素，放在提示词末尾：
- `背景简洁，不要杂乱元素`
- `保持人脸，不要改变面部特征`
- `不要文字水印`
- `不要过度曝光`

## API 生图（两种方式）

### 方式一：BytePlus / 火山方舟 Ark API（推荐）

Bearer Token 鉴权，OpenAI 兼容接口格式。

**接口**：

```
POST https://ark.cn-beijing.volces.com/api/v3/images/generations
Authorization: Bearer <ARK_API_KEY>
```

海外：`https://ark.ap-southeast.bytepluses.com/api/v3/images/generations`

**请求体**：

```json
{
  "model": "doubao-seedream-4-5-251128",
  "prompt": "你的提示词",
  "size": "2K",
  "sequential_image_generation": "auto",
  "sequential_image_generation_options": {"max_images": 6},
  "stream": false,
  "response_format": "url",
  "watermark": false
}
```

**可用模型**：

| 模型 | 说明 |
|------|------|
| `doubao-seedream-4-5-251128` | Seedream 4.5，最高分辨率，支持组图/流式 |
| `doubao-seedream-4-0-250828` | Seedream 4.0，稳定版 |
| `doubao-seedream-3-0-t2i-250415` | Seedream 3.0，支持 seed/guidance_scale |

**关键参数**：

| 参数 | 说明 |
|------|------|
| `model` | 必填，模型名称 |
| `prompt` | 必填，提示词（≤300 汉字或 600 英文单词） |
| `size` | `"2K"` / `"4K"` / `"2560x1440"` 等 |
| `sequential_image_generation` | `"auto"` 组图 / `"disabled"` 单图 |
| `response_format` | `"url"` 或 `"b64_json"` |
| `watermark` | 是否添加水印 |

**尺寸速查**：

| 宽高比 | 推荐尺寸 | 用途 |
|--------|----------|------|
| 1:1 | 2048×2048 | 头像、方形图 |
| 16:9 | 2560×1440 | 横屏、PPT |
| 9:16 | 1440×2560 | 手机竖屏、短视频封面 |
| 4:3 | 2304×1728 | 传统横向照片 |
| 3:4 | 1728×2304 | 竖向照片 |

**Agent 工作流**：

1. 用本 Skill 的提示词规则生成 prompt
2. 用户确认 prompt 内容
3. 调用 Ark API 生成（使用 exec 工具执行 curl 或脚本）：

```bash
curl -X POST "https://ark.cn-beijing.volces.com/api/v3/images/generations" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -d '{
    "model": "doubao-seedream-4-5-251128",
    "prompt": "确认后的提示词",
    "size": "2K",
    "response_format": "url"
  }'
```

4. 解析返回 JSON 中的图片 URL，展示给用户
5. 图片 URL 有效期 **24 小时**，需及时下载

### 方式二：Python generate.py（火山 AccessKey/SecretKey）

适用于使用火山引擎 AccessKey/SecretKey 的场景，自动提交任务、轮询结果、下载图片到 `output/`。

**环境准备**：

```bash
pip install -r {baseDir}/requirements.txt

# 凭证二选一：
# 方式 A：在 {baseDir}/ 下创建 .env 文件
echo "VOLC_ACCESSKEY=your_ak" >> {baseDir}/.env
echo "VOLC_SECRETKEY=your_sk" >> {baseDir}/.env

# 方式 B：环境变量
export VOLC_ACCESSKEY=your_ak
export VOLC_SECRETKEY=your_sk
```

**用法**：

```bash
# 文生图
python {baseDir}/generate.py --prompt "一只猫在花园里玩耍，水彩风格"

# 图像编辑（输入参考图）
python {baseDir}/generate.py --prompt "将背景换成海滩" --image-urls "https://example.com/photo.jpg"

# 指定分辨率
python {baseDir}/generate.py --prompt "电商主图" --width 2560 --height 1440

# 组图生成
python {baseDir}/generate.py --prompt "生成4张春夏秋冬盲盒组图" --no-force-single
```

**参数**：

| 参数 | 说明 |
|------|------|
| `--prompt` | 必填，提示词 |
| `--image-urls` | 参考图 URL（最多 10 张） |
| `--width` / `--height` | 输出宽高（需同时传） |
| `--size` | 输出面积（像素），默认 2K |
| `--force-single` | 只输出 1 张图（默认） |
| `--no-force-single` | 允许多张组图 |
| `--output-dir` | 保存目录，默认 `output/` |
| `--watermark` | 添加 AI 水印 |

**Agent 工作流**：

1. 生成 prompt → 用户确认
2. 询问「需要多张（组图）吗？」
3. 执行 `python {baseDir}/generate.py --prompt "<prompt>"`（多张加 `--no-force-single`）
4. 等待返回，图片自动下载到 `output/`

## 与 Seedance 2.0 视频生成的配合

AIGC 短剧完整工作流：

1. **用 Seedream 生成角色参考图**（本 skill）
   - 按角色设定写提示词，生成正面全身高清人像
   - 确认角色外貌满意后保存图片
2. **用 Seedance 2.0 生成视频**（seedance2-video skill）
   - 上传角色参考图作为 `@图片N`
   - 按分镜脚本写视频提示词
   - 生成 15 秒片段 → 续写延长
